## 1. Program Contracts, Locked Cross-Slice Interfaces & Shared Invariants

### 1.1 Canonical Wire Protocol (`0xF0 0xB0`) & Security Rules
All modern client-server features share a single multiplexed subcommand (`0xB0`) on `0xF0` (`KrriosClientSpecial` in CrossUO; `AssistantProtocol` in ModernUO `[UOContent-only]` registered at `[CallPriority(11)]` with `ingame: true`, requiring zero edits to `AssistantProtocol.cs`):

```text
[0xF0][u16 len][0xB0][u8 op][payload]
```

- **Framing & Version Negotiation**: `u16 len` is the total UO packet byte length including the 3-byte `[0xF0][u16 len]` header (`5 + payloadBytes`). Initial `clientProtoVer = 1`; negotiated once during session handshake (`0x01 Hello` / `0x02 Welcome`) with no redundant per-frame `protoVer` header. `ADR-002` (`MOD-003`) locks the canonical `0x06` `slotKind`, `rarity`, and `statId` enum tables.
- **Frame Payload Caps**:
  - Inbound (Client -> Server): `<= 512 bytes` per `0xF0 0xB0` frame.
  - Outbound (Server -> Client): `<= 4096 bytes` per `0xF0 0xB0` frame.
- **Zero Unsolicited Frames & Post-Handshake Lifecycle**: ModernUO never emits `0xF0 0xB0` unless the client initiates `0x01 Hello` and receives `0x02 Welcome`. Server capability state is stored in `ConditionalWeakTable<NetState, ModernClientCaps>` with proactive cleanup in `EventSink.BeforeDisconnected` (`Action<Mobile>` in `Projects/Server/Events/EventSink.cs`, guarding `if (m.NetState is { } ns)`). `AssistantProtocol.Register` uses `unsafe delegate*<NetState, SpanReader, void>`. `MOD-005` exposes `ModernProtocolRouter.RegisterNegotiatedHandler(ulong capBit, Action<NetState, ModernClientCaps> callback)` invoked immediately after `0x02 Welcome` is sent, so reconnect/initial pushes (`0x09 PetDirective`, active-instance `0x0A InstanceStatus`) run strictly post-`Welcome` rather than on synchronous `PlayerLoginEvent`. Stock/classic clients remain 100% wire-compatible.
- **Exact Canonical Opcodes (`0x01`–`0x0A`, all big-endian, all durations in `u32` milliseconds)**:
  - `0x01 Hello (C -> S)`: `(u16 clientProtoVer, u64 requestedCapFlags, u8 requestedViewRange)` — 11 B (`MOD-005`, `MOD-006`; `clientProtoVer = 1`). Single-handshake idempotency enforced per session.
  - `0x02 Welcome (S -> C)`: `(u16 negotiatedProtoVer, u64 enabledCapFlags, u8 maxViewRange)` — 11 B (`MOD-005`, `MOD-006`).
  - `0x03 CastBar (S -> C)`: `(u32 casterSerial, u8 state, u16 spellId, u32 remainingMs, u32 totalDurationMs, u8 flags)` — 16 B (`MOD-022`; emitted to self + nearby negotiated clients via `GetClientsInRange` for both player `ActionBarHud` and enemy/boss `BossBarHud`; `state`: `0=Start, 1=Update, 2=Finish, 3=Interrupt`; `flags`: bit0=interruptible, bit1=channeled).
  - `0x04 Cooldown (S -> C)`: `(u8 category, u16 actionId, u32 remainingMs, u32 totalDurationMs)` — 11 B (`MOD-022`; `category`: `0=Spell, 1=Potion, 2=Bandage [reserved/optional], 3=Skill [reserved/optional], 4=Ability`).
  - `0x05 GroundTelegraph (S -> C)`: `(u32 telegraphId, u8 action, u8 shape, u8 dangerType, i16 worldX, i16 worldY, i8 worldZ, u16 primaryRadiusFx16, u16 secondaryParamFx16, u16 angleDeg, u16 arcDeg, u32 remainingMs, u32 totalDurationMs)` — 28 B (`MOD-023`, `MOD-024`; `action`: `0=Spawn, 1=Update, 2=Cancel, 3=Detonate`; `shape`: `0=Circle, 1=Cone, 2=Line, 3=Ring`; `primaryRadiusFx16`: radius or line length in 1/16 tiles; `secondaryParamFx16`: `0` for circle/cone, inner radius for `Ring`, half-width for `Line`, in 1/16 tiles; `angleDeg`: `0..359`, `0° = +X` East, clockwise in UO Y-down world space; `dangerType`: `0=Damage, 1=Lethal, 2=Interrupt, 3=Heal`).
  - `0x06 StructuredItemTooltip (C <-> S)`:
    - `C -> S Request`: `(u32 itemSerial)` — 4 B (rate-limited `<= 10/s`; server enforces `from.CanSee(item)` + range/container ownership authZ).
    - `S -> C Snapshot`: `(u32 itemSerial, u32 revisionSeq, u32 oplHash, u8 slotKind, u8 rarity, u16 statCount [<= 64], [statCount * (u16 statId, i32 value, i32 maxValue)])` — max 656 B `<= 4096 B` (`MOD-025`; monotonic `revisionSeq` invalidates client cache even when stock `0xD6` `oplHash` is unchanged; `slotKind`/`rarity`/`statId` enums locked in `ADR-002`).
  - `0x07 StashTabSync (C <-> S)` — metadata-only organizational tabs over `BankTabBag : Container` inside `BankBox` (all item moves execute via stock `0x07`/`0x08`/`0x3C` + canonical `Container.TryDropItem` legality checks; server mandates `from.BankBox?.Opened == true` + `BankBox` capacity check before `CreateTab`, denying invalid mutations with player feedback + fresh `0x02 Snapshot` resync):
    - `subOp=0x01 RequestSnapshot (C -> S)`: `(u8 subOp)` (1 B).
    - `subOp=0x02 Snapshot (S -> C)`: `(u8 subOp, u32 bankBoxSerial, u8 tabCount [<= 16], [tabCount * (u8 tabIndex, u32 containerSerial, u16 iconId, u16 hue, u8 nameLen [<= 32], utf8[nameLen])])` (max 678 B `<= 4096 B`).
    - `subOp=0x03 CreateTab (C -> S)`: `(u8 subOp, u16 iconId, u16 hue, u8 nameLen [<= 32], utf8[nameLen])`.
    - `subOp=0x04 UpdateTab (C -> S)`: `(u8 subOp, u8 tabIndex, u16 iconId, u16 hue, u8 nameLen [<= 32], utf8[nameLen])`.
    - `subOp=0x05 DeleteTab (C -> S)`: `(u8 subOp, u8 tabIndex)` (only succeeds if empty).
  - `0x08 CombatEvent (S -> C)`: `(u32 eventSeq, u32 sourceSerial, u32 targetSerial, i32 amount, u8 eventType, u8 element, u16 flags)` — 20 B (`MOD-026`; `eventType`: `0=Damage, 1=Heal, 2=Crit, 3=Resist, 4=Miss, 5=Block, 6=Immune, 7=Interrupt`; `element`: `0=Physical, 1=Fire, 2=Cold, 3=Poison, 4=Energy, 5=Direct`; `flags`: bit0=petOwned, bit1=dot, bit2=overkill).
  - `0x09 PetDirective (C <-> S)`: `(u32 petSerial, u8 directive, u32 targetSerial, u8 roleState)` — 10 B (`MOD-027`; `directive`: `0=Aggressive, 1=Defensive, 2=Passive, 3=DodgeTelegraph, 4=TauntHold`; `roleState`: `0xFF=Locked (< Lvl 10)`, else `PetCombatRole` enum byte; `C -> S` ignores client-supplied `roleState` and enforces `pet.ControlMaster == from`; `S -> C` pushes on post-`Welcome` `RegisterNegotiatedHandler(Cap_PetDirective, ...)`, `CreatureEvents.ControlMasterChangedEvent` tame/transfer/release, and level-10 `PetCombatRole` unlock).
  - `0x0A InstanceStatus (S -> C)`: `(u16 instanceId, u8 state, u8 scalingTier, u8 difficultyScalar, u32 elapsedMs, u32 remainingMs, u16 objectivesMask, u8 bossPhase)` — 16 B (`MOD-036`; `state`: `0=None/Exit, 1=Active, 2=Completed, 3=Failed, 4=Evacuating`; pushes on instance transition and post-`Welcome` `RegisterNegotiatedHandler(Cap_InstanceStatus, ...)`).
- **Locked `u64` Capability Bitmask Layout**:
  - `bit 0`: `Cap_CastBar` (`0x03`) | `bit 1`: `Cap_Cooldown` (`0x04`) | `bit 2`: `Cap_GroundTelegraph` (`0x05`) | `bit 3`: `Cap_StructuredTooltip` (`0x06`) | `bit 4`: `Cap_StashTabs` (`0x07`) | `bit 5`: `Cap_CombatEvent` (`0x08`) | `bit 6`: `Cap_PetDirective` (`0x09`) | `bit 7`: `Cap_InstanceStatus` (`0x0A`) | `bit 8`: `Cap_DynamicViewRange` (`0xC8` > 18, conditional `MOD-028`).
- **Mandatory Security & Rate-Limit Rules**: Every inbound `0xF0 0xB0` opcode (`0x01`, `0x06`, `0x07`, `0x09`) enforces max payload length (`<= 512 B`), single-handshake idempotency, per-opcode token-bucket rate limits (`0x06 <= 10/s`, `0x07 <= 4/s`, `0x09 <= 6/s`), and server-authoritative entity ownership/visibility checks (`from.CanSee(item)`, `from.BankBox?.Opened == true`, `pet.ControlMaster == from`).
