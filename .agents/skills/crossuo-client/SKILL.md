# CrossUO client

Read the [CrossUO fork guide](../../../../crossuo/AGENTS.md) in the paired
checkout. Find existing input, gump, settings, and packet paths before adding
new ones. Keep use, targeting, dragging, and modifier behavior intact outside
the feature scope. Exercise the normal interaction after building the client.

Use [CrossUO diagnostic toggles](../../../../crossuo/docs/ENVVARS.md) for render
or UI validation. Compare the same viewport, scene, and backend when measuring
performance. Keep captures and test profiles local. Treat client display as
separate from authoritative ModernUO results.
