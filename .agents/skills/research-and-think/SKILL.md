# Research before changing a dependency or rule

Check the current code first. For an existing toolchain, read its pinned
version and installed help or headers. For new dependencies, use primary
documentation or source and verify the exact version, API, and behavior.

For Excelsior features, use the [archive guide](../../../dev-docs/references/uoex/README.md)
and keep capture provenance. Distinguish what the wiki says, what current
ModernUO or CrossUO does, and what the owner wants. State material uncertainty.
Translate the evidence into a small testable change, with a reason for any new
dependency or protocol.
